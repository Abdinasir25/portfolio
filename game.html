JavaScript Flappy Bird Game

I made this game while completing the W3Schools JavaScript tutorial. I modified the game by changing the colors, adding a background image, styling the buttons, adding a Play Again button, and centering the game.

Use the FLAP WINGS button to stay in the air. Try to avoid the barriers and see how long you can fly.
